## The entry

> On Monday mornings, my alarm clock and my bed fight over custody of me. The bed always wins. I stay in.

## How it works

`main.ts` (Node 22+) writes the joke to `/output/entry.txt`. The program
self-checks the gate before writing: the text must be 1–200 characters
and not only whitespace, with no trailing newline.

```sh
node main.ts
cat /output/entry.txt
```
